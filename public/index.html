MTU

1500 is the standard Ethernet MTU and the fastest setting. This app used to force 1280 on the belief that a smaller packet always means less latency, which is backwards - 1280 is the IPv6 minimum, not an optimisation. The fragmentation probe that decided this at runtime was unreliable, so the value is simply fixed at 1500.

TCP/IP Stack & NIC Hardware Offloading
Disable Nagle's Algorithm (TCPNoDelay)
Transmits packets immediately without waiting for TCP ACK bundling. Drops network hitching in games.
Disable Delayed ACKs (TcpAckFrequency = 1)
Forces Windows to acknowledge every incoming TCP packet instantly (zero millisecond delay).
Disable Windows Network Throttling
Removes 10-packet throttling limit on multimedia & gaming connections (NetworkThrottlingIndex = 0xFFFFFFFF).
Receive Side Scaling (RSS)
Spreads network processing across CPU threads. Windows already enables RSS by default, so this only makes sure it is on - and turning it OFF now restores that default instead of disabling it. It does not set FastOpen.
NIC Hardware Checksum Offloading
Shifts packet checksum math to NIC hardware (Realtek 2.5GbE), relieving CPU cycles.
Via Network Tweaks
Disable Energy Efficient Ethernet (EEE)
Prevents NIC from entering micro-sleep states during quiet moments, eliminating wake-up lag.
Via Network Tweaks
Remove QoS Reserved Bandwidth
Stops Windows reserving 20% of bandwidth for QoS (NonBestEffortLimit = 0).
Expand Ephemeral Ports + Fast Recycle
65534 max user ports and 30s TIME_WAIT for high-connection games.

GPU & Display Latency Optimizations

Hardware-Accelerated GPU Scheduling (HAGS)
GPU manages its own VRAM and scheduling directly without Windows kernel mediation. Decreases input lag.
Windows 11 Windowed Game Flip Optimizations
Low-latency Modern Flip Model on borderless/windowed games. Windows enables this by default — OFF explicitly disables it.
Disable GameDVR & Background Recording
Completely disables Xbox background game recording service, freeing 5-15% GPU/CPU overhead.
Elevate GPU MSI Interrupt Priority to HIGH
Sets AMD RX 6750 XT / NVIDIA interrupt priority to Priority 1 (High) for instant frame dispatch.

CPU Invariant Timers & Memory Latency
Disable Dynamic Ticks (Prevent Timer Drift)
Stops CPU timer frequency changes during gaming, eliminating timer drift and micro-stutters.
Enforce Native Invariant TSC (useplatformtick)
Forces Windows kernel to use high-precision sub-microsecond hardware CPU timestamp counters.
Lock Windows Kernel in RAM (DisablePagingExecutive)
Locks core Windows kernel and drivers into physical RAM, eliminating SSD page hitches during intense gameplay.
Hybred Low Latency Power Scheme & USB Suspend
Applies the Hybred Low Latency plan and disables USB selective sleep. It differs from Ultimate Performance in 35 power settings, and the ones that matter keep the CPU out of its idle states and out of boost ramp-down, so it stays at full clock instead of dropping between frames. Costs higher idle heat and fan noise.
Not recommended for laptops with bad cooling
